# YSYX E4 Digital Logic Experiments

This repository contains my solutions to the [YSYX E4 assignment](https://ysyx.oscc.cc/docs/2607/e/4.html#%E5%AE%8C%E6%88%90%E6%95%B0%E5%AD%97%E7%94%B5%E8%B7%AF%E5%AE%9E%E9%AA%8C), based on [南京大学 计算机科学与技术系 数字逻辑与计算机组成 课程实验](https://nju-projectn.github.io/dlco-lecture-note/index.html).

This repository is used to document my completed coursework. To run the experiments on another machine, you’ll need to set up environment for Verilator and, for the virtual board exercises, NVBoard, which're not covered in this repo.
